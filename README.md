## Selected projects

A selection of deployed applications spanning full-stack development, AI engineering, design systems, and distributed systems.

### 1. [OmniCanvas](https://github.com/pranav-666/omnicanvas) — AI Collaborative Design Engine

[Live demo](https://omnicanvas-navy.vercel.app)

An interactive infinite-canvas workspace with GPU-accelerated rendering, natural-language layout synthesis, real-time collaboration using Yjs CRDTs, and export to React components.

**Stack:** React · WebGL / Canvas 2D · Yjs · FastAPI · Tailwind CSS

### 2. [CogniaBG](https://github.com/pranav-666/cogniabg) — Multimodal Neural Search Platform

[Live demo](https://cogniabg.vercel.app)

A document intelligence platform combining BM25 and dense vector retrieval, Reciprocal Rank Fusion, citation grounding, and Server-Sent Events for streamed responses.

**Stack:** Next.js · Python · Qdrant · BM25 · Dense Retrieval · RRF · SSE

### 3. [Aura UI](https://github.com/pranav-666/aura-ui) — Headless Design System

[Live demo](https://aura-ui-ruby.vercel.app)

A typed, accessible React component system with compound component patterns, design tokens, keyboard navigation, and interactive component documentation.

**Stack:** React 19 · TypeScript · WCAG 2.1 AA · Storybook · Tailwind CSS

### 4. [SentinelAI](https://github.com/pranav-666/sentinelai) — Autonomous Code Review Swarm

[Live demo](https://sentinelai-vert.vercel.app)

An event-driven GitHub App and dashboard using cooperating LLM agents to review pull requests, validate webhook signatures, identify security issues, and generate tests.

**Stack:** Python · FastAPI · React · LangChain · HMAC Webhooks

### 5. [PulseStream](https://github.com/pranav-666/pulsestream) — Real-Time Telemetry & Event Streaming

[Live demo](https://pulsestream-peach.vercel.app)

A real-time event processing platform built around Kafka, Go services, ClickHouse analytics, WebSocket feeds, and a high-performance visualization dashboard.

**Stack:** Go · Apache Kafka · ClickHouse · WebSockets · React

### 6. [Enterprise Data Intelligence & Agent Platform (EDIA)](https://github.com/pranav-666/Enterprise-Data-Intelligence-Agent-Platform-EDIA)

An operational intelligence platform combining deterministic analytics, hybrid document retrieval, anomaly detection, bounded multi-agent investigations, and a read-only MCP tool server.

**Stack:** Python · FastAPI · React · TypeScript · PostgreSQL · RAG · MCP
